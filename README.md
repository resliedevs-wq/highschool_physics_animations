# highschool_physics_animations

Created in [T3 Code](https://t3.codes).

## Animations

Each animation is a single self-contained HTML file. Open it directly in a browser; no build step or internet connection is needed.

- [Traveling wave: period, wavelength and phase](traveling-wave/index.html): y = A·sin(2π/T·t − 2π/λ·x)
- [Interference of two sources](interference/index.html): y = A₁·sin(2π/T·t − 2π/λ·r₁) + A₂·sin(2π/T·t − 2π/λ·r₂ − φ₀)
- [Standing wave: fixed–fixed and fixed–open](standing-wave/index.html): y = A·sin(2π/T·t − 2π/λ·x) + A·sin(2π/T·t − 2π/λ·(2L − x) + π)
